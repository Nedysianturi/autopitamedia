Deotorisasi Aplikasi Threads

Aplikasi Auto PitaMedia Studio telah menerima pemberitahuan pelepasan akses akun Threads Anda.

Catatan Operasional:
Auto PitaMedia Studio adalah aplikasi desktop lokal mandiri. Kredensial akun Threads disimpan secara lokal di komputer pengguna. Setelah deotorisasi ini, token akses Anda di Meta tidak akan lagi dapat digunakan untuk publikasi. Anda dapat menghapus data akun lokal kapan saja melalui menu Pengaturan di aplikasi desktop.

Jika memerlukan konfirmasi manual lebih lanjut, hubungi operator di Cipadata@gmail.com.
