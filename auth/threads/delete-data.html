Data Deletion Policy & Instructions

Penghapusan Data Pengguna Threads

Halaman instruksi dan penerimaan permintaan penghapusan data pengguna untuk integrasi Meta Threads API.

Kebijakan & Arsitektur Penyimpanan:
1. Auto PitaMedia Studio beroperasi dengan arsitektur local-first mandiri pada komputer lokal pengguna.
2. Server web Netlify publik ini hanya bertindak sebagai relay otorisasi dan tidak pernah menyimpan data pribadi, profil, maupun token pengguna di server/cloud.
3. Seluruh data akun Threads disimpan secara lokal di basis data SQLite lokal milik pengguna.

Cara Menghapus Data Lokal:
• Buka aplikasi Auto PitaMedia Studio di komputer Anda.
• Masuk ke menu Pengaturan Akun ➔ pilih Akun Threads ➔ klik Hapus / Putuskan Koneksi.
• Semua token dan data cache lokal akan langsung dihapus permanen.
