Kebijakan Privasi (Privacy Policy)

Terakhir diperbarui: 28 September 2026

Kebijakan Privasi ini menjelaskan bagaimana Auto PitaMedia ("kami", "aplikasi") mengumpulkan, menggunakan, dan melindungi informasi Anda saat menggunakan perangkat lunak otomatisasi publikasi media sosial kami, termasuk integrasi resmi dengan TikTok Content Posting API, Meta Graph API (Facebook & Instagram), dan YouTube Data API.

1. Informasi yang Kami Kumpulkan

Kami hanya mengumpulkan data teknis minimum yang mutlak diperlukan untuk memfasilitasi publikasi video atas izin eksplisit Anda:

  • Informasi Autentikasi Akun (OAuth Tokens): Token otorisasi aman (Access Token) yang diberikan langsung oleh platform pihak ketiga (TikTok, Meta, Google) saat Anda menghubungkan akun Anda.
  • Informasi Dasar Profil Publik: Identifikasi unik akun (User ID / Channel ID / Page ID) dan nama tampilan (*Display Name*) untuk menampilkan status koneksi di antarmuka aplikasi Anda.
  • Data Konten Video: File video lokal, judul konten, teks caption, dan hashtag yang Anda pilih untuk diterbitkan.
  • Data Metrik Publikasi: Jumlah tayangan (*views*), suka (*likes*), dan komentar dari konten yang diterbitkan untuk keperluan analitik performa Anda.

2. Penggunaan Data & Kepatuhan API Pihak Ketiga

Data yang kami peroleh hanya digunakan untuk:

  • Mengunggah video dan materi visual ke akun media sosial yang telah Anda tentukan (TikTok, Instagram Reels, YouTube Shorts, Facebook Page).
  • Menjalankan jadwal penerbitan otomatis sesuai preferensi waktu yang Anda atur.
  • Menampilkan ringkasan wawasan analitik performa konten di dashboard pengguna.

3. Kepatuhan Khusus API TikTok (TikTok Developer Terms Compliance)

Dalam memanfaatkan TikTok Content Posting API:

  • Aplikasi ini hanya mempublikasikan video yang secara eksplisit dipilih dan disetujui oleh pengguna.
  • Kami TIDAK PERNAH mengakses pesan pribadi (DM), daftar kontak pribadi, riwayat penjelajahan, atau data rahasia non-publik dari akun TikTok Anda.
  • Kami tidak membagikan, menjual, menyewakan, atau mentransfer data pengguna TikTok kepada pihak ketiga, broker data, atau jaringan periklanan manapun.

4. Penyimpanan & Keamanan Data

Auto PitaMedia memprioritaskan keamanan privasi berbasis arsitektur lokal (*local-first*):

  • Kredensial token tersimpan secara terenkripsi di lingkungan lokal pengguna.
  • Seluruh komunikasi transmisi data ke server resmi (TikTok, Meta, Google) dilakukan melalui protokol terenkripsi berstandar industri HTTPS (TLS 1.3).

5. Hak Pengguna & Penghapusan Data (Data Deletion)

Pengguna memiliki kendali penuh atas akun dan datanya setiap saat:

  • Pencabutan Izin Akses: Anda dapat mencabut izin akses Auto PitaMedia kapan saja langsung dari pengaturan keamanan akun Anda di aplikasi TikTok (Settings & Privacy ➔ Security ➔ Manage App Permissions), Facebook, atau Google Account.
  • Permintaan Penghapusan Data: Jika Anda ingin menghapus seluruh data kredensial dari aplikasi kami, Anda dapat menghapusnya langsung dari menu pengaturan akun di aplikasi atau menghubungi kami melalui email di bawah ini.
