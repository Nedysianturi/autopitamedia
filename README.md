# Auto PitaMedia 🚀
> Official Web Landing Page, Privacy Policy & Terms of Service for Auto PitaMedia Social Media Automation Platform.

Designed to fulfill developer requirements for **TikTok for Developers (Content Posting API)**, **Meta Developer Platform (Facebook & Instagram)**, and **Google YouTube Data API v3**.

---

## 🌐 Live URLs (When Deployed to Vercel/Netlify)
- **Homepage:** `https://autopitamedia.vercel.app/`
- **Privacy Policy:** `https://autopitamedia.vercel.app/privacy.html`
- **Terms of Service:** `https://autopitamedia.vercel.app/terms.html`

---

## ⚡ 1-Click Deploy to Vercel
1. Open [Vercel](https://vercel.com/) and log in with your GitHub account.
2. Click **"Add New..."** ➔ **"Project"**.
3. Select this repository: `Nedysianturi/autopitamedia`.
4. Click **"Deploy"**.
5. Your website will be live in 10 seconds!
